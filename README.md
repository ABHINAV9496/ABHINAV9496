## 🚀 Featured Projects

### ⚡ [EcoCharge — Smart EV Charging & Trip Planning Platform](https://github.com/ABHINAV9496)
🔗 **[Live Demo](https://ecocharge-nine.vercel.app)**

A full-stack Indian EV trip planner and charging platform combining geospatial routing, real-time systems, and an AI agent.

- Built a concurrent-safe slot reservation engine (`select_for_update()` inside atomic transactions) with overlapping time-window detection, and integrated Razorpay for payment capture, refunds, and signature verification
- Developed a FastAPI microservice powering a multi-tool LLM agent (Groq/Llama 3.3) with RAG via pgvector + SentenceTransformers, Redis-backed memory, prompt injection guards, and PII/Aadhaar redaction
- Designed a segment-by-segment energy-aware route planner using vehicle-specific charging curves, OSRM routing, Redis-cached distance matrices, and concurrent weather fetching
- Built a 4-source data pipeline (Open Charge Map, Kaggle, HuggingFace, synthetic highway generation) with PostGIS spatial indexing across 400+ cities and 55+ highway corridors
- Shipped a React (Vite + Tailwind) frontend with Leaflet maps and Recharts dashboards; containerized 6 services and deployed to AWS EC2 via GitHub Actions CI/CD, with real-time updates over Django Channels + WebSockets

**Stack:** `Django` `FastAPI` `PostgreSQL/PostGIS` `pgvector` `Redis` `Celery` `Django Channels` `Docker` `React` `Leaflet`
