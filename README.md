## ⚡ EcoCharge — Smart EV Charging & Trip Planning Platform
**[Live Demo](https://ecocharge-nine.vercel.app)** | **[Repository](https://github.com/ABHINAV9496)**

A full-stack Indian EV trip planner and charging platform combining geospatial routing, real-time systems, and an AI agent.

- 🔋 Concurrent-safe slot reservation engine using `select_for_update()` inside atomic transactions with overlapping time-window detection, integrated with Razorpay for payments and refunds
- 🤖 FastAPI microservice powering a multi-tool LLM agent (Groq/Llama 3.3) with RAG via pgvector + SentenceTransformers, Redis-backed memory, prompt injection guards, and PII/Aadhaar redaction
- 🗺️ Segment-by-segment energy-aware route planner using vehicle-specific charging curves, OSRM routing, Redis-cached distance matrices, and concurrent weather fetching
- 📊 Data pipeline ingesting from 4 sources (Open Charge Map, Kaggle, HuggingFace, synthetic highway generation) with PostGIS spatial indexing across 400+ cities and 55+ highway corridors
- 🖥️ React (Vite + Tailwind) frontend with Leaflet maps and Recharts dashboards; 6 containerized services deployed to AWS EC2 via GitHub Actions CI/CD, with real-time updates over Django Channels + WebSockets

**Stack:** `Django` `FastAPI` `PostgreSQL/PostGIS` `pgvector` `Redis` `Celery` `Django Channels` `Docker` `React` `Leaflet`
